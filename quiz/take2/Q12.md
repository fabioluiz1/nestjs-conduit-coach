# Q12 — AI Usage: weak vs strong Cline prompt

## Question (as asked — business-framed after two re-poses)

You're directing Cline to add the server-side validation that rejects an article with an empty title
or body. You write: *"Add validation to article creation."* Weak or strong? Why — and what would you
send instead?

(Re-posed twice: first version anchored to "your Q2 answer" — violated the restate-the-spec rule;
second version named all the technical pieces in a "Spec:" block — showed the answer. Final version
gives only the business goal. Both coaching defects fixed in `02-VOICE.md`.)

## Candidate's answer (final, after iterations)

Weak. Must give unambiguous file paths, explain the validation, and ensure all actions consuming the
DTO get `@UsePipes`. Final prompt:

> Change `@src/article/dto/create-article-dto.ts` to validate title and body are not empty.
> Grep the src folder to list the places where `CreateArticleDto` is used, then make sure all the
> routes consuming it are annotated with `@UsePipes` with a pipe from
> `@src/shared/pipes/validation.pipe.ts`.
> You can use the patterns already established by `@create-user.dto` (validation annotations) and
> `@user.controller` (`@UsePipes` annotation).

## Coach grade

**3-star.** Full anatomy: @-mention the file to change + **reference files to model on** for *both*
the DTO (`create-user.dto`) and the controller (`user.controller`), the **gotcha** (repo's own
`validation.pipe.ts`, not `@nestjs/common`), correct **fields** (title + body), and a grep-for-consumers
that covers create **and** update. Strong agentic move delegating the enumeration to Cline.

Polish (not graded down): the `@`-paths are imprecise (`create-article-dto.ts` → `create-article.dto.ts`;
`@create-user.dto` → `…create-user.dto.ts`; `pioes` → `pipes`). A broken `@`-mention makes Cline guess —
exact paths matter.

## Note

Reaching 3-star took two prompt iterations: weak → added fields + gotcha + grep (2-star) → added the
"model it on X" reference files (3-star). The reference-file lever was the 2★→3★ jump.
